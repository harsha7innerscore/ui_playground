# water-reminder

Menu-bar companion app (macOS): Neo from The Matrix walks in from the bottom-left corner on a timer, asks you to drink water, celebrates when you say yes. Modeled directly on [hydrate-buddy](https://github.com/sharada-dev/hydrate-buddy), rebuilt with our own Neo art instead of a pixel-art character.

## Tech stack
- Electron (`^28.3.3`, bundles Node 18.18.x) — chosen specifically to stay on the Node 18 line per workspace policy; do not bump Electron to a version that bundles Node 20+ without updating that policy first.
- Plain HTML/CSS/JS renderer, no frontend framework (app is three small windows: reminder toast, settings, tray menu — a framework would be overhead).
- `.nvmrc` pins `18.20.4` for local `npm install`/dev; use `nvm use` before running `npm install`.
- `npm audit` reports several Electron advisories (sandbox/renderer-escape, AppleScript injection in `moveToApplicationsFolder`, etc.) that come with staying on 28.x. Accepted risk: this app loads only its own local files, never remote or user-supplied content, so the realistic exposure is near zero. Revisit if that ever changes.

## Dev commands
- `nvm use && npm install` — one-time setup
- `npm start` (= `electron .`) — run the app
- Config is persisted to `~/Library/Application Support/water-reminder/config.json`, not in the repo. Delete it to re-trigger onboarding.

## Architecture
- `main.js` — the whole main process: config load/save, active-hours + interval scheduling (`setTimeout` chain, not `setInterval`, so interval/active-hours changes take effect cleanly), tray + its menu (quick interval radio buttons, settings, pause, quit), and the two `BrowserWindow`s (reminder toast, settings/onboarding).
- `renderer/` — reminder toast (`index.html`/`renderer.js`/`style.css`: slide-in from off-screen, idle→drinking sprite swap, confetti, slide-out) and settings/onboarding (`settings.html`/`settings.js`), each with its own `contextIsolation`-safe preload (`preload.js`, `settings-preload.js`) — no `nodeIntegration` in either renderer.
- `assets/idle.png`, `assets/drinking.png` — transparent-background Neo sprites generated by `scripts/make_sprite.py` from the user's own comic panels (`assets/source/panel_*.png`, `assets/source/water_break.gif` — kept for reference, not loaded by the app).
- `assets/tray-icon.png` — droplet silhouette, `setTemplateImage(true)` so macOS auto-adapts it to light/dark menu bars.
- `scripts/make_sprite.py` — crops a panel and flood-fills its background to transparent (brightness-threshold + border-connected flood fill + feathered edge; see the comment above `BRIGHT_THRESHOLD` for why distance-to-one-sampled-color didn't work — the source art has a real lighting gradient across the background).

## Notes
- macOS-only in its current form (dock-hiding, template tray icon, bottom-left corner math use `screen.getPrimaryDisplay().workArea`, which is cross-platform in Electron, but this hasn't been tested on Windows/Linux).
- No network calls, no telemetry, no secrets. Name/interval/hours are stored locally only.
- Previous iteration of this project was a Python/tkinter popup driven by launchd — replaced entirely (see git history) once the user asked to copy hydrate-buddy's model. Do not resurrect the tkinter path; if Python/Tk is ever needed again on this machine, remember system `/usr/bin/python3` has Tk 8.5, which renders images as solid black on current macOS — use a venv off `/opt/homebrew/bin/python3.12` (needs `brew install python-tk@3.12` for Tk 9.x) instead.
